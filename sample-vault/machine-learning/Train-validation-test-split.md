# Train-validation-test split

The training set teaches parameters, the validation set guides choices, and the test set estimates performance on data that stayed out of the decisions. Reusing the test set for tuning quietly turns it into another validation set. [[Data leakage]] is often a boundary mistake rather than a clever modeling trick.
