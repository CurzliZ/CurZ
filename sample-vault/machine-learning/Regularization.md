# Regularization

Regularization expresses a preference for simpler parameter settings when several models fit the training data. It can reduce variance, but excessive regularization can erase real structure. Compare it against a stable [[A reliable baseline]] and inspect the validation behavior rather than treating a penalty as an automatic improvement.

Related: [[Overfitting]], [[Gradient descent]]
