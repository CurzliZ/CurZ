# Noisy labels change the answer

When labels encode inconsistent judgments, more rows can make the wrong target look more certain. Before increasing a dataset, inspect disagreement by source and category. This qualifies the intuition in [[More examples usually help]]: volume helps only when the measurement process is trustworthy.
