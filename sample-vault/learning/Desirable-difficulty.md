# Desirable difficulty

A challenge can improve learning when it requires effortful retrieval and still leaves a path to correction. Difficulty without feedback can simply reinforce confusion. This is why [[Interleaving]] and [[Feedback is information]] belong together rather than being treated as separate tricks.
